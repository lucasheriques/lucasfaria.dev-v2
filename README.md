# lucasfaria.dev

Lucas Faria's site, built as static HTML with [Astro](https://astro.build).

Posts are MDX files in `content/bytes` and `content/ideas`. Files in `content/drafts` are validated but never published.

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # static site in dist/
pnpm preview      # serve dist/
pnpm check        # astro check
pnpm lint
pnpm test
```
